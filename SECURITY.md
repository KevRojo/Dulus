# Security

**Report vulnerabilities privately to security@dulus.ai.** Please don't open a public issue for a security problem.

A good report includes the app version, your operating system, the steps to reproduce it, and what you expected to happen instead. If you find a way to reach data that isn't yours, stop there and tell us — don't go further.

This repository holds documentation only; there's no source code in it. The same address works for the open-source core, [Dulus](https://github.com/KevRojo/Dulus).

Every report gets the same treatment as any other change to the Dulus desktop app: it's reproduced first, fixed at the root, and pinned with a regression test that fails on the old code. See [how the desktop app is built](ENGINEERING.md#the-rules-every-change-follows).
