# The Dulus app is not just the public CLI with a window

If you found Dulus through this repository, you found the **open-source core**—not the full desktop product. They share the Dulus name and build on the same agent foundation, but they are different editions with different scope.

**The public repo is a real, useful terminal agent. The downloadable Dulus app is the much larger, integrated product built around that foundation.** Installing this repo with `pip install dulus` will not give you the desktop app, and the desktop app is not currently buildable from this public source tree.

> Want the full app? **[Download Dulus](https://dulus.ai/download/)**. Want the open-source core? Keep exploring this repo.

## What the difference looks like

| | **Dulus open-source core** | **Dulus desktop app** |
|---|---|---|
| **Where it lives** | This public repository | A separate, private application codebase |
| **How you use it** | Install and run the Python CLI | Download and run the desktop app, with its desktop and connected surfaces |
| **What it gives you** | The agent runtime and the open-source tools and integrations in this repo | The CLI foundation plus a full desktop experience: visual workspace, browser and terminal panels, voice, phone access, and integrated workflows |
| **Collaboration** | Use the CLI agent and extend the open-source project | Coordinate a Round Table of agents, with shared tasks and human approvals |
| **Computer interaction** | Work through the CLI and its available tools | See and control the screen, with a live overlay and the ability to watch, approve, or stop actions |
| **Models and extensions** | Use supported providers and extend the public project | Choose from 40+ provider integrations, local models, hosted models, MCP servers, skills, and plugins through the app |
| **Source and license** | Public source under GPLv3 | App source is private; this repository does not contain the full app implementation |
| **Cost** | Free to use; provider/model costs may apply | The app is free with your own keys or local models; Dulus-hosted models use Fuel |

The app also brings together capabilities like Astral Voice, Telegram, persistent memory, image and video generation, checkpoints, and task management. See the [full product overview](https://github.com/KevRojo/Dulus#one-agent-made-of-many) and [download page](https://dulus.ai/download/) for the current details.

## Why are they separate?

The open-source project is the foundation and remains useful on its own. The desktop app grew into a broader product—with its own interface, integrations, packaging, and connected experiences—that does not live in this public repository. That is why the public CLI can be excellent and still look much smaller than the app: **this repo is not the complete app source**.

We want that distinction to be clear, not to diminish the open-source project. Use the CLI if you want the public code, a terminal-first agent, or a place to contribute. Get the app if you want the complete desktop experience.
